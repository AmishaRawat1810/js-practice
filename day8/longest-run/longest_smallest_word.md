**Youngest and Eldest Member**
In a family of words, find the youngest and the eldest member. The youngest member has the smallest set of letters and the eldest member has the longest set of letters.

Constraint
-> string ≤ 100

**Requirements**
	•	Input: a string (may contain letters, spaces).
	•	Output: <youngest member> <length>
            <eldest member> <length>
If there are more than 1 eldest members 

**Example**

input : "my name is Alexander"
output : "my" 2
         "Alexander" 9

**Test case**
Input               |       Output
"this is a cake"    |   "a" 1   "this"  4
